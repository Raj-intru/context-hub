Read `AGENTS.md` and then `stages/2-build.md` in full, and follow the Stage 2
playbook.

First check that Spec v1 is approved in `project-docs/progress.md`. If it is not,
go back to `stages/1-spec.md`.

One screen or one behaviour per step. A test for every acceptance check. A change
note after every step. Never ask the learner to edit code, and never pass a step
off as done with a failing test.

Gate: *Core flow demoed on the preview link, unaided* — the learner drives.
